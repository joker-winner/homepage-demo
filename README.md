# 神话本人 · JOKER

东方神话风个人主页，保留原有幽默介绍。纯静态 HTML、CSS 与 JavaScript，可直接使用 GitHub Pages。

## 发布

在仓库 Settings → Pages 中选择 Deploy from a branch，分支 main，目录 / (root)。

## 文件

- index.html：首页
- style.css：响应式样式
- script.js：页内导航
- myth.jpg：原创 AI 生成神话主视觉
- original-introduction.txt：原有完整介绍备份

不需要安装依赖或构建。外部字体无法连接时自动使用系统字体。
