# 年报问答检索评测：结论

## 口径（按课件第 61–63、90–92 页）

全景题的单位是公司。先判断问题形状、列出每家公司需要的证据字段，再按公司召回候选；之后分别评估证据覆盖和答案。候选块进入结果不代表相关，更不代表答案正确。需要回到原文核验公司归属、报告年度、合并/母公司口径、指标定义、单位和页码；缺口应逐项列出，不得用其他公司或行业常识补齐。

本次题库在 Q03、Q04、Q07、Q10 设置了十家公司全景题，Q09 为双公司比较。逐题候选召回和公司覆盖明细见 `evaluation/results.csv`，题目与评分标准见 `evaluation/questions.csv`。

## 结果

历史版人工评测为 **5/10**：具体单公司数值题相对较好；定性风险归纳和双公司召回会翻车。历史版四道“跨公司题”只涉及青岛啤酒、燕京啤酒，不能证明行业全景能力。

修订后按公司分别召回，Q03（营业收入+归母净利润）、Q04（绿色实践）、Q07（经营指标）和 Q10（经营举措）均已生成逐公司候选与缺口状态。候选相关性检查中，Q03、Q04 有公司未取得符合字段条件的块；Q07、Q10 的词面规则显示十家公司均有候选，但仍须人工核对原文。**新版全景答案尚未完成逐家公司人工核验，因此不报新版总正确率，也不把候选覆盖计作答案通过。**

| 问题类型 | 当前观察 |
|---|---|
| 事实数值题 | 单公司且字段集中时较好，能从页级证据核对数值和单位。 |
| 跨公司全景题 | 旧版全局 Top-6 与两家公司优先轮询会漏掉公司；新版逐公司候选提高了覆盖可见性，但候选仍需逐家审查相关性。 |
| 定性风险题 | 风险列表被外汇风险或股东承诺等相似词片段干扰；必须命中风险因素原文。 |
| 多字段答案 | 收入、归母净利润、同比等字段必须同时满足，不能用单一指标块或章节目录替代。 |

## 错误原因与改进

主要问题是检索范围和题目证据义务未匹配：固定 Top-K 不能覆盖十家公司；平均轮询可能只覆盖公司名称，不覆盖题目主题；关键词命中不能证明上下文有效。现已把全景问答拆成逐公司候选并显示候选出处，评测表将召回、公司级证据覆盖、答案核验分栏记录。下一步需人工确认每家公司的原文块，再补齐可被证据支持的逐公司答案；缺字段时标明未找到，不猜答。
